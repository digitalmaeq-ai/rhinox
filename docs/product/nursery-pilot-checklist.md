# Nursery 1 Term 1 Week 1: pilot checklist (draft)

Purpose: find out whether a novice teacher or parent can run the lesson from the guide alone. Running the pilot needs the owner's approval, an unlisted preview link and named participants.

## Before
- [ ] Owner approves an unlisted preview link (no search indexing) or another route.
- [ ] 3–5 teachers and 3–5 parents named. Participation is voluntary; get consent first (Nigeria Data Protection Act 2023).
- [ ] Guide `guide-nursery-1-term-1-week-1.md` given as the only instructions.
- [ ] Device list noted (phone, tablet, laptop) and one paper-only (no device) participant included.

## During (observer notes, no child names)
- [ ] Did they start without help? Minutes to first screen.
- [ ] Did they tap "Yes, I watched them do it" only after watching?
- [ ] Did anyone hit a dead end, or not understand a label?
- [ ] Did the no-device route work?

## After (counts, not percentages)
Report as "x of n". Questions: could you start alone; what was unclear; would you use it again; what would you change.

## Pass rule (proposed)
No dead ends, no instruction that caused a wrong action, and most participants start without help. Any dead end must be fixed and re-tested before the pilot counts as passed.

## Privacy
Record nothing that identifies a child. Observer notes use participant numbers only.
